A lecture is a list

The lecture file just lists its slides, in order.

---
title: Anatomy of a lecture
type: lecture
weight: 1
slides:
  - /slides/lectures/a-lecture-is-a-list.md
  - /slides/lectures/a-slide-file.md
  - /slides/lectures/columns.md
---

How slides and lectures fit together.

The title slide, the contents slide and the “any questions?” slide at the end are made for you.

To reorder the lecture, move the lines in the list.

A slide is a file

Each slide lives in its own file in content/slides/. This is the start of this one:

---
title: A slide is a file
classes: [burger, gap]
params:
  layout:
    cols: 3fr 2fr
    rows: auto 1fr auto
---

> Each slide lives in its own file in `content/slides/`.

The classes and layout lines are optional: leave them out and the slide is one column. Folders inside slides keep things tidy, one folder per topic.

The settings go between the --- lines; everything below them is the slide.

Reuse

A slide can appear in as many lectures as you like. This module’s Python slide is in two:

# content/code/on-slides/index.md
title: Code on slides
type: lecture
slides:
  - /slides/code/same-as-pages.md
  - /slides/code/python.md
  - /slides/code/java.md

# content/advanced-lectures/layouts/index.md
title: Slide layouts and types
type: lecture
slides:
  - /slides/advanced/unknown-class.md
  - /slides/code/python.md

Write a good explanation once and use it in a lecture, a revision session and a colleague’s module. Fix it once and every lecture that uses it is fixed.

6

Presenting

Present straight from Learning Zone or the website, on any computer with a browser.

Arrow keys or swipe to move. The bar at the bottom shows how far through you are.

Full screen button (or press f) in Learning Zone, so the slide fills the projector.

Press m on the website for the menu, to jump to another part of the module.

There is no file to carry around and nothing to install in the lecture theatre. Each slide has its own address (?slide=5), so you can link straight to it.
