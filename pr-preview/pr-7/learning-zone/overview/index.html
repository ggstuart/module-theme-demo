What happens

Every time you commit a change to main, GitHub rebuilds both.

GitHub builds your text files into a website and a Learning Zone package.

1

What you get in Learning Zone

One import gives you:

a folder for the module

a folder for each unit

a topic for each lecture and exercise

all in the same order as on the website

Lectures stay slide decks, and exercises keep their contents list and copy buttons. Everything is inside the package, so it works without the website.

2

Three steps

From GitHub to your module in three steps.

Step 1: Download course-package.zip from GitHub

Step 2: Import it in Learning Zone (Module Tools > Course Admin > Import/Export/Copy Components)

Step 3: Check the new folder in your module’s Content

The zip is on the run’s page of the Learning Zone package workflow, under Artifacts.

3

Changing things later

An import is a copy of your materials at that moment.

Learning Zone: when you change your materials, the Learning Zone package workflow builds a fresh zip. Import it, then hide or delete the old folder.

The website is always up to date by itself: every commit to main rebuilds it within a few minutes.

Import again whenever you want Learning Zone to catch up.
