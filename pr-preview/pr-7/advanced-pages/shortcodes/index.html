ref and relref

These work: the shortcode on its own, not inside a Markdown link.

  • {{< ref "/writing/cheat-sheet" >}} gives https://ggstuart.github.io/module-theme-demo/pr-preview/pr-7/writing/cheat-sheet/
  • {{< relref "/writing/cheat-sheet" >}} gives /module-theme-demo/pr-preview/pr-7/writing/cheat-sheet/
  • A site path without a leading slash, [the cheat sheet](writing/cheat-sheet/): the cheat sheet
  • With a leading slash, [the cheat sheet](/writing/cheat-sheet/): the cheat sheet (see Known bugs (h))
  • Page-relative, [the last page of this unit](../toc-and-nav/): the last page of this unit (see Known bugs (h))

Inside a Markdown link, as [text]({{< ref ... >}}), see Known bugs. The {{% ref %}} form inside a link works: the cheat sheet, with {{% ref %}} and with {{% relref %}}.
