Unit: Code listings

Paste code in, and students get it coloured, numbered and ready to copy. No more fighting Word’s formatting.

In Word, code loses its indentation, quotes turn curly, and colours have to be added by hand, if at all. Here you put the code between two lines of three backticks, say which language it is, and the rest is done for you, in exercises and on slides alike.
