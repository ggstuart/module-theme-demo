1

The idea

Write your materials once, as plain text. Get slides, exercises and a website for free. Put them in Learning Zone with one upload.

No PowerPoint, no Word, no copying and pasting between them.

2

What you write

---
title: Photosynthesis
---

Plants turn **light** into food.

- needs water
- needs carbon dioxide
- makes oxygen

This is all there is to a slide.

A few lines at the top give it a title. Below that you just type, using **stars** for bold and - for bullet points.

3

What students see

Plants turn light into food.

  • needs water
  • needs carbon dioxide
  • makes oxygen

The same text, styled and laid out for you. Students move through slides with the arrow keys, by swiping on a phone, or with the buttons at the bottom.

4

One source, two places

                 your text files
                        |
           +------------+------------+
           |                         |
       a website              a Learning Zone
   (for anyone, any         package (one zip file,
    time, any device)        imported into a module)

Both are built automatically, so they never get out of step.

5

Why bother?

  • Fast to write: no fiddling with text boxes or fonts
  • Consistent: every slide and page has the same, accessible style
  • Easy to update: fix a typo in one place, everywhere is fixed
  • Shareable: colleagues can reuse your slides in their own lectures
  • Safe: every change is saved, and you can always go back
  • Works everywhere: phones, tablets, screen readers
  • Code friendly: coloured code examples with copy buttons
  • Yours: plain text files that will still open in 20 years
6

So, how hard is it?

If you can write an email, you can write these materials.

You need a free GitHub account and a web browser. Nothing needs installing, and the rest of this module shows you every step.

7

What is Markdown?

Markdown is plain text with a few symbols that mean “make this a heading”, “make this bold” or “this is a list”.

You type it in any text editor, or straight into GitHub in your browser. The website and Learning Zone turn it into nicely formatted pages.

8

Headings

## Learning outcomes

### By the end of this week

Start a line with # symbols to make a heading. Two ## for a main heading, three ### for a smaller one.

On exercise pages, headings also build the contents list automatically.

Links and pictures

A picture is the same, with a ! in front. The words in square brackets describe the picture for screen readers.

13

The bit at the top

---
title: Week 3 lab
type: exercise
weight: 3
---

Every file starts with a few settings between --- lines.

  • title is the page title
  • type says what it is: lecture, exercise or unit
  • weight puts pages in order: 1 comes first

That's it

Headings, bold, lists, links, pictures and code cover almost everything.

There is a one page cheat sheet to keep handy.

What you get in Learning Zone

  • a folder for the module
  • a folder for each unit
  • a topic for each lecture and exercise
  • in the same order as on the website

Lectures stay slide decks, and exercises keep their contents list and copy buttons. Everything is inside the package, so it works without the website.
