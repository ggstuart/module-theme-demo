Teaching materials with Hugo

This small module shows what it is like to write teaching materials as plain text files and publish them both as a website and as content in Learning Zone. It is written for lecturers who have never used Markdown or a static website.

If you teach programming, start with Code listings: code you paste in is coloured, numbered and easy to copy, with nothing to format by hand.

The basics

  1. Start here: what is this, and what do students see?
  2. Code listings: code in exercises and on slides, in any language.
  3. Getting started: your own copy, in five minutes.
  4. Write your own: a page in Markdown, an exercise and a lecture.
  5. Into Learning Zone: one zip file, imported in three clicks.

Going further

The Advanced units use every feature of the theme, and the Known bugs unit shows what doesn’t work yet, with a workaround for each. They double as a test bed for changes to the theme.

Everything you are looking at, including this page, was written in the same way you will write yours.
