Unit: Known bugs

Things that don’t work yet in the theme (version 2026-27), one page each, with a live example and a workaround.

Each page shows the broken case for real, so when a fix reaches the theme the page changes by itself. Each also says what is wrong, how to work around it, and which change fixes it (Fixed in).

In this unit

(A) Ref Inside a Markdown Link

A Markdown link whose address is a {{< ref >}} or {{< relref >}} shortcode points to a broken address.

exercise

(B) Pale Slide Text Without Colours.css

Slide text is pale grey on a pale slide when a site has no colours.css.

lecture

(C) Theme Settings Lost Without _Merge = 'Deep'

A site’s own [outputs] or [markup] settings replace the theme’s, unless they say _merge = 'deep'.

exercise

(D) Copy Buttons Only for Some Languages

Only code blocks marked html, css, js, JavaScript, json, php or phtml get a “copy to clipboard” button.

exercise

(E) Iframe With a Page-Relative Address

{{< iframe src="demo/" >}} looks for demo/ at the top of the site, not next to the page.

exercise

(F) a Slide as a Page of Its Own Is Unstyled

slide

(G) HTML Files in Content/ Stop the Build

With Hugo 0.162 or later, any .html file in content/ stops the build, unless the site allows it.

exercise

(H) Links Starting With / or ../ Lose the Site's Folder

On a site that lives in a folder (every GitHub Pages project site, such as …github.io/module-name/), links that start with / or ../ miss out the folder.

exercise

(I) HTML Files Next to an Exercise Aren't Published

An iframe of an HTML file in an exercise’s own folder shows the site’s home page instead.

exercise
