(b) Pale slide text without colours.css

Slide text is pale grey on a pale slide when a site has no colours.css.

Known bugs

Contents

  1. What is wrong
  2. Workaround

What is wrong

If this text is hard to read, the bug is still there. Fixed in: ggstuart/Module#5 (pending merge)

The theme’s style.css uses --clr-slide-text for slide text, but its own default for it is commented out. Sites such as web-application-development set it in their colours.css. A site without one gets pale text.

1

Workaround

Define the colour in your own stylesheet (one of the customcss files):

1
2
3

:root {
    --clr-slide-text: hsl(0, 10%, 10%);
}

This site does that in static/css/example.css, except on this lecture (any page with a slide of class known-bug-unpatched), so the bug shows here and nowhere else.
