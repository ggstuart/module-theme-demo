## Exercise pages

You are reading an **exercise page**.
Exercises are for work students do at their own pace, such as lab sheets, tutorials or reading.

Notice the **contents list** at the top.
It is made automatically from the headings on the page, so long exercises are easy to find your way around.

## Try the slides

Go back to the lecture [Why write materials this way?](welcome/why/).

1. Click on the slide.
2. Press the **right arrow** key to move forward and the **left arrow** key to go back.
3. Try the **full screen** button at the bottom right.
   Press `Esc` to leave full screen.

> On a phone or tablet, swipe left and right instead.

## Code examples

Many modules include code.
Code examples are coloured automatically, with line numbers.
Web code (HTML, CSS, JavaScript, JSON and PHP) also gets a **copy to clipboard** button, so students can paste it straight into their own work.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>My first web page</title>
</head>
<body>
    <h1>Hello, Learning Zone!</h1>
</body>
</html>
```

Try the button, then paste into any document.
