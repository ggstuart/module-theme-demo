> Headings, bold, lists, links, pictures and code cover almost everything.

| You type | You get |
|---|---|
| `## Learning outcomes` | a heading |
| `**important**` | **bold** text |
| `*careful*` | *italic* text |
| `- apples` | a bullet point |
| `1. Read the brief` | a numbered list |
| `[the handbook](https://…)` | a link |
| `![a description](picture.svg)` | a picture |
| ```` ```python ```` … ```` ``` ```` | a coloured code listing |
