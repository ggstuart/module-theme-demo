> Start a line with `#` symbols to make a heading.

```markdown {linenos=false}
## Learning outcomes

By the end of this week you will be able to...

## Lab tasks

### Task 1: make a folder

### Task 2: add a page
```

Two `##` for a main heading, three `###` for a smaller one.
Use them to break a long exercise into steps students can find again.

> On exercise pages, headings also build the contents list automatically.
