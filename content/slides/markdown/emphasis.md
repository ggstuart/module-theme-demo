> One star either side for *italic*, two for **bold**, backticks for `code`.

```markdown {linenos=false}
This is *important*.

This is **very important**.

Type `ls` to list the files.
```

> This is *important*.
>
> This is **very important**.
>
> Type `ls` to list the files.

> What you type is on the left, what students see is on the right.
