> A list is one item per line.

```markdown {linenos=false}
- apples
- pears

1. Read the brief
2. Plan your answer
3. Write it up
```

> - apples
> - pears
>
> 1. Read the brief
> 2. Plan your answer
> 3. Write it up

> Start a line with `-` for a bullet point, or with a number for a numbered list.
